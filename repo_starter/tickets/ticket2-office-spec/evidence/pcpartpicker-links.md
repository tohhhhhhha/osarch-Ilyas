# Build links and compatibility

**What this file proves:** each build is a real, orderable set of parts from one Kazakhstan vendor, and the parts fit together according to their own product pages.

PCPartPicker has no Kazakhstan region and no Kazakhstan shops, so it cannot show tenge prices or local stock. Prices therefore come from the shop.kz product pages, linked below and in `budget.csv`.

## Compatibility, checked against the product pages

| Check | What the pages say | Result |
|---|---|---|
| CPU fits the board | Ryzen 5500GT, 5700G and 5700X pages: AM4, Zen 3. A520M-K and B550M-A pages: AM4, Zen 2 / Zen 3 | OK |
| Memory fits the board | Kits are DDR4-3200; both boards list DDR4 | OK |
| Picture without a graphics card | 5500GT and 5700G pages list built-in graphics; the 5700X page says "Отсутствует", so the designer has the RTX 5060 | OK |
| SSD fits | NV3 is M.2 2280 PCIe 4.0; A520M-K has 1 M.2, B550M-A has 2 | OK |
| Cooler fits | AG400 page lists AM4; all three CPUs are OEM without a cooler | OK |
| Power | RTX 5060 OC Low Profile page: minimum PSU 450 W; FSP VIC-550BD is 550 W | OK |
| Board and card fit the case | CG380 page: Micro-ATX, graphics card up to 410 mm | OK |
