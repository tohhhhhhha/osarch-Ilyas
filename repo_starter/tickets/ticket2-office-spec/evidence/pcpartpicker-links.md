# Build links

**What this file proves:** each build is a real, orderable set of parts from one Kazakhstan vendor, and the parts are compatible with each other.

PCPartPicker has no Kazakhstan region and no Kazakhstan shops, so it cannot show tenge prices or local stock. Prices therefore come from shop.kz product pages (links below and in `budget.csv`). ## Compatibility checks done by hand

| Check | Result |
|---|---|
| CPU socket = board socket | All CPUs are AM4; A520M-K and B550M-A are AM4 |
| Memory type = board memory type | DDR4 kits on DDR4 boards |
| Built-in graphics where there is no graphics card | 5500GT (Vega 7) and 5700G have graphics; 5700X has none, so the designer has the RTX 5060 |
| A520 board supports Ryzen 5000G | Yes, A520 was released for Ryzen 3000/4000G/5000 |
| SSD slot | NV3 is M.2 NVMe; A520M-K has 1 M.2 slot, B550M-A has 2 |
| Cooler fits AM4 | DeepCool AG400 lists AM4 |
| Power | RTX 5060 page lists a 550 W minimum; the designer has 650 W |
| Case fits a micro-ATX board | CG380 is listed in the shop's micro-ATX case category |
